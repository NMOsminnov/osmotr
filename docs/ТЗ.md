# «Осмотр» — техническое задание

Приложение Android для фотофиксации при осмотрах оборудования: папки (с
вложенностью) создаются прямо в приложении; зашёл в папку — «Снимать» — снимаешь
штатной камерой телефона — вернулся, снимки уже в папке. Снимков в папке — сотни,
без тормозов; на снимке можно отметить нужное.

Цель — **максимально быстрый и удобный осмотр**, без лишнего: никаких настроек,
переключателей и пояснений в приложении (автор, 08.10.2026: «мы просто делаем снимки,
перейдя в папку в приложении. Не грузи пользователя деталями»).

## 1. Сценарии

| № | Сценарий | Как должно быть |
|---|---|---|
| С1 | Начать осмотр | «+ папка» → имя («ТЭЦ-2») → внутри ещё («Насос 1») |
| С2 | Снимать | в папке «Снимать» → штатная камера → снять сколько нужно подряд → «назад» (жест или кнопка) → снова в папке, снимки уже в ней, новые сверху |
| С3 | Комментарий к папке | меню папки → «Добавить комментарий» → карточка вверху папки, касание — правка; файл `Комментарий.txt` в самой папке (виден по USB, идёт в архив) |
| С4 | Выбрать много | зажать снимок или папку → отмечено; повести, не отпуская, — отмечается всё по пути, у края сетка листается сама; касание — добавить или снять |
| С5 | Действия с выбранным | переместить (снимки и папки), отправить (с папками — одним архивом), удалить |
| С6 | Пересмотреть снятое | сетка 3–4 в ряд; просмотр — зум с полным разрешением по месту (шильдик читается) |
| С8 | Найти папку | значок поиска → набрать название, номер или инв. номер → список по приоритету → касание — в папку |
| С9 | Контакты людей | меню папки → «Контакты» → «Добавить» (или из телефонной книги) → файл `Контакты.xlsx` в самой папке (ФИО, должность, телефон, почта, примечание; правится и в Excel); касание телефона — звонок, почты — письмо; поиск находит папку по человеку и телефону |
| С11 | Проверить структуру | значок дерева вверху → «Структура»: всё дерево раскрыто, у папки число снимков (пустые — «пусто»), значки комментария и контактов; касание — в папку |
| С12 | Перенести папку в дереве | в «Структуре» зажать папку → вести → отпустить на папку; верхний уровень — плашка «Осмотры», выезжает снизу на время переноса (не листать вверх); над свёрнутой 0,2 с — раскрывается; у края — прокрутка; внизу «Отменить» |
| С13 | Перенести несколько папок | в «Структуре» зажать и отпустить — папка отмечена, дальше касания отмечают; потащить любую отмеченную — едут все; у каждой строки — число папок и снимков внутри |
| С10 | Вернуться в папку | положение прокрутки помнится: из вложенной папки или просмотра — на то же место |
| С14 | Осмотр по описи | описи раздельно: на главном — «Новая опись» (файл Excel → имя → своя папка `Осмотры/<опись>/`, внутри — как раньше в «Осмотрах»); описи на главном — строками с «осмотрено N из M», касание — сразу в опись, «Папки» — её папки; одна опись на папку, исправленный файл — «Заменить файл описи» (папки предметов остаются); прежние кучи описей при запуске разносятся по своим папкам; листы — списки, столбцы находятся сами (№, инвентарник, наименование, первонач. стоимость, сумма, приоритет, статус); спорное — окно с примерами значений; там же «Листы»: галочкой — какие листы брать в опись (снятый не попадает ни в список, ни в счётчики, ни в отчёт; вернуть — меню «Листы и столбцы»); после загрузки книги с несколькими листами окно открывается само |
| С15 | Найти предмет и снять | в описи: набрал номер с бирки (без разделителей, латиница = кириллица) → касание → папка предмета (имя — инвентарник) → «Снимать»; вернулся — отмечен, поиск чист |
| С16 | Похожие предметы | зажать несколько в описи → «В одну папку» → «777 1001 +2 шт», состав — `Инвентарники.txt`; в папке предмета «Ещё такие же в описи — сюда же» (подсказка) и «Добавить из описи»: весь список с поиском, отметить несколько (касание — добавить/убрать), применяется разом «Готово +N −M» или «назад»; имя папки короткое — инвентарник (до 48 знаков) и «+N шт»: длинные пути ломаются в Windows |
| С17 | Сколько осмотрено | «Осмотрено N из M» и по приоритетам «П1 5/7…» (касание — только этот приоритет); отчёт «Осмотр — <опись>.xlsx» в папке объекта: итог по спискам и приоритетам, лист на список (Да/Нет, снимков, папка), обновляется сам |
| С7 | Отдать результат | по USB — папка `Осмотры` в корне памяти; без провода — «Отправить архивом» |

### Человеческий фактор

| Ошибка | Что делает приложение |
|---|---|
| Удалил не то (снимки или папку) | удалённое — в корзину; внизу «Удалено: … · Вернуть»; корзина чистится через сутки; папку перед удалением ещё и подтвердить |
| Снял не в ту папку | выбрать → «Переместить» |
| Создал папку не на том уровне | «Переместить папку» (в саму себя и во вложенную — нельзя; занято имя — «Имя (2)») |
| Ушёл из камеры кнопкой «Домой», потом снимал своё | в папку ложится только снятое в пределах 2 часов от начала захода |
| Во время съёмки пришли фото в мессенджер, сделан снимок экрана | в папку — только файлы самой камеры (Android 10+ знает, какое приложение записало файл); снимки экрана — никогда |
| Приложение выгрузилось, пока открыта камера | заход хранится на диске — снятое ляжет при следующем открытии |
| Папки поменяли с компьютера | при возвращении в приложение папка перечитывается; исчезнувшая — ближайшая существующая |
| Имя с «/», «:» и т. п. | недопустимые знаки заменяются; занятое имя не принимается |
| Села батарея сразу после записи комментария или контактов | запись во временный файл, сброс на диск, подмена — файл либо прежний, либо новый целиком |
| Перенёс папку не туда | окно переноса — дерево всех папок; переносимая и её вложенные приглушены |
| Нет приложения камеры | сообщение «На телефоне нет приложения камеры» |

## 2. Требования к скорости (проверяемые)

- Холодный запуск приложения — ≤ 1 с; «Снимать» → камера — мгновенно (штатная).
- Перенос сотни снимков по возвращении — доли секунды (переименования).
- Ни один снимок не декодируется в память ради сетки: сетка читает миниатюры
  (≈ 384 px, ≈ 15–30 КБ), сделанные в фоне при съёмке.
- Сетка папки на 2000+ фото листается без пропуска кадров (ленивая сетка,
  кэш миниатюр, стабильные ключи).

## 3. Хранение

- **Папка в корне памяти телефона: `Осмотры/…`** (автор, 08.10.2026: «если на
  телефоне в корне будет директория с разбитыми файлами — сразу можно удобно
  выгрузить»). Подключил по USB — скопировал `Осмотры` целиком, всё уже разложено
  по папкам осмотра.
- Папка в приложении = настоящий каталог: вложенность, переименование и перенос
  — операции файловой системы, без базы данных.
- Разрешения: на Android 11+ — «Доступ ко всем файлам» (запись в корень
  памяти иначе невозможна; приложение ставится APK-файлом, не из магазина); на
  Android 8–10 — запись в память.
- Каждый новый файл сразу регистрируется в системе (MediaScanner): иначе по USB и
  в галерее его не видно до перезагрузки телефона.
- Имена снимков: `<папка>_<ГГГГММДД_ЧЧММСС>_<NNN>.jpg` — сортируются по
  времени, по имени понятно, откуда фото.
- Миниатюры — во внутренней памяти приложения (повторяют вложенность), в
  выгружаемую папку не попадают; потерянная — пересоздаётся.
- Выгрузка без провода: ZIP потоком (без копии в памяти) → «Поделиться».

## 4. Съёмка — штатной камерой

- Своей камеры в приложении нет: снимает штатная, со всеми настройками и
  алгоритмами телефона (автор: «лучше передать снимок встроенному приложению
  системы… бесшовно интегрировать»).
- «Снимать» открывает камеру в обычном режиме — без подтверждения каждого кадра —
  как ожидающую результата, внутри задачи приложения: «назад» из камеры возвращает в
  папку, а не в галерею камеры.
- Заход (папка и время начала) запоминается на диске; по возвращении всё снятое за
  заход переносится из DCIM в папку осмотра одним проходом: один запрос к системе,
  переименование в пределах памяти, регистрация и миниатюры — пачкой в фоне. Кадры,
  которые камера дописывает после возврата (HDR и т. п.), подбираются.
- JPEG и HEIC — как пишет камера.

## 5. Практики, на которые опирается решение

- **Штатная камера** (`INTENT_ACTION_STILL_IMAGE_CAMERA`) вместо своей: настройки,
  HDR, ночная съёмка, шумоподавление и видоискатель производителя — без единой
  строки своей камеры; снятое находится через MediaStore по времени захода.
- **Фоновые миниатюры**: однопоточный исполнитель, `inSampleSize` при
  декодировании (никогда не декодировать 12 МП ради миниатюры), поворот по EXIF.
- **Compose**: `LazyVerticalGrid` с ключами по пути файла, Coil 3 с явным
  размером запроса и кэшем в памяти; тяжёлое (обход каталогов, подсчёт) — в
  `Dispatchers.IO`, на экран — готовые списки.
- **Без базы данных**: файловая система — единственный источник правды; нечему
  рассинхронизироваться при сбое.
- **Удаление необратимо** — подтверждение с числом файлов; переименование
  проверяет занятость имени.

долгое действие — шкала; на каждую ошибку — понятная причина.
