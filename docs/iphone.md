# «Осмотр» на iPhone (SideStore)

Приложение для iPhone ставится не из App Store, а через **SideStore**: он подписывает
приложение вашим Apple ID. Это бесплатно и разрешено Apple, но подпись живёт **7 дней** —
SideStore продлевает её сам, если телефон бывает в **Wi-Fi** с включённым **LocalDevVPN**.

> Сверено с документацией SideStore (docs.sidestore.io). Шаги на живом iPhone ещё проверяются —
> если что-то на экране выглядит иначе, сообщите.

## Что нужно

- iPhone на iOS 16 или новее, с кодом-паролем.
- Компьютер с Windows 8 или новее (64-битный) и USB-кабель — **только для первой установки**.
- Apple ID (любой; бесплатного достаточно). Подойдёт и не тот, что на телефоне.
- Wi-Fi.

## Установка (один раз, минут 15)

**На компьютере**

1. Поставить **iTunes** (лучше с сайта Apple) и **iLoader** (установщик SideStore, файл `.msi`).
2. Подключить iPhone кабелем. На телефоне нажать **«Доверять»** и ввести код.
3. Открыть iLoader → войти Apple ID → выбрать свой iPhone → **«Install SideStore (Stable)»**.

**На iPhone**

4. Поставить из App Store приложение **LocalDevVPN**.
5. «Настройки → Основные → VPN и управление устройством» → свой Apple ID → **«Доверять»** →
   «Разрешить и перезапустить».
6. Там же, внизу, включить **«Режим разработчика»** — телефон перезагрузится.
7. Открыть **LocalDevVPN → «Подключить»** (на вопрос о VPN — «Разрешить»).
8. Открыть **SideStore**, войти тем же Apple ID → «Мои приложения» → нажать счётчик «7 дней».
9. Скачать на телефон файл **`Osmotr.ipa`** (по ссылке, из мессенджера или «Файлов»).
10. В SideStore: «Мои приложения» → **«+»** → выбрать `Osmotr.ipa`. Через минуту на экране
    появится «Осмотр».

## Каждую неделю (30 секунд)

Раз в неделю телефон должен побывать в **Wi-Fi** — дома, в офисе:

1. Включить **LocalDevVPN**.
2. Открыть **SideStore** → «Мои приложения» → **«Обновить всё»**.

Если неделю не обновлять — «Осмотр» перестанет открываться, но **снимки и описи не пропадут**:
после обновления всё на месте. Если истёк и сам SideStore — нужна повторная установка с
компьютера (шаги 1–3, 8).

## Как не потерять снимки

- Каждый снимок сразу пишется в приложение **и копией в «Фото»** (спросит разрешение один раз —
  «Разрешить»). Даже если удалить приложение, снимки останутся в галерее.
- Описи, отчёты и снимки по папкам видны в «Файлах»: **«На iPhone → Осмотр → Осмотры»**.
- После выезда — «Выгрузить» в описи: отчёт Excel или архив, в мессенджер или «Файлы».

## Ограничения

- Не больше **3 приложений** через SideStore на один Apple ID (SideStore — одно из них).
- Мобильный интернет для установки и продления **не подходит** — нужен Wi-Fi.
- Опись из WhatsApp: «Поделиться» → «Осмотр» (или сохранить в «Файлы» и выбрать в «Новая опись»).
