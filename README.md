# Осмотр

Приложение для осмотров оборудования по описям: снимки по папкам предметов, опись из Excel
(столбцы находятся сами — в любом шаблоне), поиск по инвентарнику и словам с опечатками,
отчёт Excel «осмотрено / не осмотрено», выгрузка архивом.

- `app/` — Android (Kotlin, Jetpack Compose). Сборка: `./gradlew :app:assembleRelease`.
- `web/` — версия для iPhone (PWA) — в работе.
- `tools/make_templates.py` — набор самых кривых описей для тестов подбора столбцов.
- `docs/ТЗ.md` — сценарии, требования, решения.

Тесты: `./gradlew :app:testDebugUnitTest`, `cd web && npx vitest run`.
