# Установщик «Осмотра» — чужой код и инструменты

- **iLoader** (github.com/nab138/iloader, MIT; © nab138) — по его образцу сделаны знакомство с
  телефоном, файл пары для SideStore и порядок установки SideStore. Название и значки iLoader не
  используются (у них отдельная лицензия).
- **isideload** (github.com/nab138/isideload, MIT) — вход в Apple ID и подпись приложений.
- **idevice** (github.com/jkcoxson/idevice, MIT) — связь с iPhone по кабелю.
- **ipatool** (github.com/majd/ipatool, MIT; © Majd Alfhaily) — LocalDevVPN из App Store; кладётся
  в установщик при сборке.
- **SideStore** (github.com/SideStore/SideStore) — скачивается с GitHub при установке, в
  установщик не входит.
- **Golos Text** (SIL Open Font License 1.1) — шрифт окна, см. `docs/licenses/GolosText-OFL.txt`.
